Como publicar alterações
  1. Adicione ou edite oradores, moderadores e sessões nesta página (as alterações ficam guardadas neste browser).
  2. Clique em Pré-visualizar site para ver o resultado.
  3. Clique em Descarregar dados.js e, se adicionou fotos, em Descarregar fotos novas.
  4. No GitHub: envie o dados.js para a pasta assets/ e as fotos para assets/img/oradores/ (Add file → Upload files). O site actualiza automaticamente.
