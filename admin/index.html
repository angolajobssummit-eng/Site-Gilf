Definições do repositório

Como obter a chave de acesso (uma vez)
  1. Inicie sessão no GitHub com a conta dona do repositório.
  2. Abra github.com/settings/personal-access-tokens/new.
  3. Em Repository access, escolha Only select repositories → site-gilf.
  4. Em Permissions → Repository permissions → Contents, escolha Read and write.
  5. Clique em Generate token, copie e cole aqui. Guarde-a num local seguro.

Alternativa mais simples: em github.com/settings/tokens/new marque public_repo, escolha a validade e clique em Generate token (começa por ghp_).

Importante: abra este admin pelo endereço do Vercel (…vercel.app/admin/), não pelo link do Claude.

A chave fica guardada só neste browser. Cada membro da equipa pode ter a sua.
