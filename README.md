# GiLF Angola–Dubai

Site oficial do **Global Investment & Leadership Forum (GiLF Angola–Dubai)** e da Gala dos **Prémios Líderes Angola 2026** — 17 de Dezembro de 2026, EPIC SANA Luanda.

Site estático (HTML/CSS/JS, sem dependências), bilingue PT/EN.

- `index.html` — conteúdo (texto em português)
- `assets/main.js` — traduções EN, contagem decrescente, formulário (envio por e-mail ou WhatsApp)
- `assets/style.css` — estilos

Para publicar: GitHub Pages, Netlify ou qualquer alojamento estático — basta enviar estes ficheiros.
